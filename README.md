# Levitas

*Latin: "lightness".*

Levitas is a lightweight game server for Minecraft: Java Edition **1.21.8** (protocol 772),
written from scratch in Rust. The goal is a server that plays like vanilla survival and
runs on a fraction of the memory and CPU a JVM-based server (Paper, Purpur, Leaf, ...)
needs, with a plugin API for survival-economy servers on top.

> **Status: playable, early.** You can join a generated world and play survival: mine,
> craft, farm, fight monsters and save your progress. Redstone, the Nether and End,
> villagers and plugins are still to come. Overall progress: **about 39%** of the
> [roadmap](docs/ROADMAP.md).

## What works today

- **Joining and multiplayer:** login, chat commands with tab completion, several players
  in one world, chunks streamed around each player.
- **World:** vanilla-style terrain with biomes, caves, aquifers, trees, ores and
  structures (generated by [Pumpkin](https://github.com/Pumpkin-MC/Pumpkin)'s
  generator), a day/night cycle, rain and thunder, light that updates as blocks change.
- **Survival:** health, hunger, fall damage, death and respawn (at your bed), mining
  speed and tool wear checked by the server, item drops from vanilla loot tables,
  experience levels and orbs.
- **Building and blocks:** block orientation and support rules, doors, fences, stairs,
  chests (also double), furnaces, crafting tables, falling sand and gravel, flowing water
  and lava, buckets, obsidian and cobblestone generators.
- **Farming and nature:** crops, saplings that grow into trees, leaf decay, grass
  spreading, bone meal, hoes, sugar cane and cacti.
- **Mobs:** cows, pigs, sheep and chickens (breeding and babies, shearing, milking,
  eggs, following food); zombies, spiders,
  creepers and skeletons that spawn in the dark, find their way to you, burn in
  daylight, explode or shoot arrows; armor; bows.
- **Saving:** everything is stored in the vanilla Anvil format (`region/`, `entities/`,
  `playerdata/`, `level.dat`), so vanilla and Leaf can open Levitas worlds.

Not there yet: redstone, the Nether and End, villagers, enchanting and brewing, boats
and minecarts, online mode (Mojang account checks) and plugins. See the
[roadmap](docs/ROADMAP.md) for the full list.

## Playing

1. Build it (below), or run `tools/deploy.ps1` on Windows to build a release into a
   separate server folder (`../levitas-server`) with a `start.bat`.
2. Start `levitas` (or `start.bat`). It listens on `127.0.0.1:25565`; pass another
   address as the first argument to change it.
3. Join with a Minecraft **1.21.8** client. Online mode is not implemented yet, so only
   run it where you trust everyone who can connect.
4. Stop the server with **Ctrl-C**: it saves the world before exiting (it also saves
   every five minutes).

Settings, through environment variables:

| Variable | Meaning |
|---|---|
| `LEVITAS_WORLD` | World folder (default `./world`) |
| `LEVITAS_SEED` | Seed of a new world (default random) |
| `LEVITAS_WORLD_TYPE=flat` | A superflat test world instead of generated terrain |

Commands: `/gamemode`, `/give`, `/kill`, `/time`, `/weather`, `/summon`, `/xp`, `/help`.

## Building

Requires Rust 1.96 or newer (install via [rustup](https://rustup.rs)), plus Python 3
and Java 21+ for the one-time data generation step.

```sh
# Downloads the official 1.21.8 server.jar and runs its data generator into generated/
python tools/datagen.py
cargo build --release
cargo run --release -p levitas-server
```

Before sending changes: `cargo fmt --all`, `cargo clippy --all-targets -- -D warnings`
and `cargo test --workspace` must pass. The tests include end-to-end tests that drive a
real server through the network protocol like a client would.

## How it is built

| Crate | What it does |
|---|---|
| `levitas-protocol` | Packet encoding and decoding, VarInts, positions |
| `levitas-nbt` | NBT, the format of saves and some packets |
| `levitas-registry` | Blocks, items, packets, tags, loot tables, recipes, biomes: generated at build time from the official data generator's output |
| `levitas-world` | Chunks, paletted storage, light and its engine, Anvil region files |
| `levitas-pumpkin` | Terrain generation through Pumpkin's generator, translated to 1.21.8 |
| `levitas-server` | The server: connections, and the world task that owns all game state |

One task owns the whole world and ticks it 20 times a second; each connection is its
own task that sends the world events and receives ready-made packets, so the game state
needs no locks. Chunk generation runs on worker threads. See
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the design and
[docs/HANDOFF.md](docs/HANDOFF.md) for a guide to the code for new contributors.

## Clean-room policy

Levitas does **not** contain code copied, translated, or decompiled from Minecraft, Paper,
or any of its forks. Behaviour is implemented from public protocol documentation, the
Minecraft Wiki, data produced by the official server's data generator, and observation of
a running server. Contributors must follow [docs/CLEAN_ROOM.md](docs/CLEAN_ROOM.md).

Levitas is not an official Minecraft product and is not approved by or associated with
Mojang or Microsoft.
